# Cap Quotidien

Application web progressive (PWA), conçue pour iPhone et Android. Les données restent dans le navigateur du téléphone.

## Mise en ligne la plus simple
1. Décompresser ce dossier.
2. Déposer son contenu sur Netlify Drop, GitHub Pages ou un hébergement HTTPS.
3. Ouvrir l'adresse obtenue sur le téléphone.
4. iPhone : Safari > Partager > Sur l’écran d’accueil.
5. Android : Chrome > menu > Installer l’application.

## Important
- L'installation PWA et le mode hors ligne exigent une adresse HTTPS.
- Exporter périodiquement les données depuis Réglages.
- Cette version n’envoie aucune donnée à un serveur et n’utilise pas d’IA distante. Son coach adaptatif fonctionne avec des règles locales simples.
